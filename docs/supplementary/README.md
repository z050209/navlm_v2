# Supplementary material (portable bundle)

Four interactive HTML viewers + the full Claude Code conversation
transcript that accompany the report. **Fully self-contained** —
every image referenced by a viewer is bundled in the `assets/`
subfolder, and all paths are relative. You can zip up this entire
`supplementary/` folder, send it to anyone, and the viewers will
work in their browser without needing the rest of the project tree.

## Interactive viewers

| File | Size | What it shows |
|------|-----:|---------------|
| `a2_mapped_GPS_spot.html`  | 162 KB | Folium / Leaflet map of every accepted frame: walker GPS (snapped to OSM walking graph), top-1 StreetView pano match, route polyline to destination. Click a marker for the per-frame popup. (Uses the Leaflet CDN — needs internet to render the basemap tiles; the data is embedded.) |
| `a2_vlmagreed.html`        |  64 KB | Side-by-side QC viewer for the 1,219-frame **VLM-agreed** cohort: query frame · 4 cardinal SV crops at the top-1 pano · DINOv2 cosine scores · heading-v2 decision (`top1` / `top1+top2`) and chosen angle. (Uses 102 bundled images.) |
| `a2_route_gt.html`         |  12 KB | 4 hand-picked route examples illustrating GT-verb computation: walker pose + OSM walking-graph route polyline + first-segment bearing → derived verb. (3 bundled images.) |
| `a2_viz_sft_nov.html`      |  12 KB | One (frame, destination) pair rendered across the 3 SFT variants (`given` / `derived` / `implicit`) in the **V-stripped (`_nov`) namespace** — i.e. with the `Visible landmarks at this spot:` block removed from the student prompt. Shows the exact instruction the trained model sees plus the teacher's GT answer. (1 bundled image.) |

## How to view

Just **double-click** any of the four `.html` files. Modern browsers
(Chrome, Firefox, Edge, Safari) all render local HTML with relative
image refs out of the box; no web server needed.

If your browser's security settings block local-file image loading
(some Chrome flags do), serve the folder over a quick local HTTP
server:

```bash
cd supplementary/
python -m http.server 8000
# then open http://localhost:8000/a2_vlmagreed.html
```

## Reproducing these from source

If you have the full project tree, each viewer is regenerated by a
script under `src/`:

| HTML | Generator |
|------|-----------|
| `a2_mapped_GPS_spot.html` | `python -m src.a2_viz_matched` (Folium map output) |
| `a2_vlmagreed.html`       | `python -m src.a2_viz_matched` (side-by-side QC output) |
| `a2_route_gt.html`        | `python -m src.a2_route_viz` |
| `a2_viz_sft_nov.html`     | `python -m src.a2_viz_sft --strip-visible --suffix _nov` |

The source-generated viewers write absolute `file:///C:/Users/...`
paths. The portable copies in this folder were created with a
post-processing step that:
1. rewrites every absolute path to start with `assets/`, and
2. copies every referenced image into `assets/` preserving the
   `cities/<...>` subpath structure.
